# Nimbus Pulse

Сайт Nimbus Pulse на Next.js, TypeScript, Tailwind CSS и Framer Motion.

## Запуск

```bash
npm install
npm run dev
npm run build
npm run start
```

Для локальной разработки откройте http://localhost:3000.

## Настройки публичной версии

Задайте значения в окружении перед сборкой или в локальном файле `.env.local`.

| Переменная | Значение |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Полный адрес основного сайта с `https://`. |
| `NEXT_PUBLIC_CONTACT_EMAIL` | Публичный рабочий email для вопросов и подключения. |
| `NEXT_PUBLIC_CONTACT_TELEGRAM_URL` | Публичная ссылка на аккаунт команды в Telegram, если он используется. |

Значения с префиксом `NEXT_PUBLIC_` видны посетителям. Храните токены и ключи отдельно. Ссылки для связи отображаются, когда задан email или Telegram.

Главная страница показывает готовые примеры диалогов. Обращения принимаются по указанным каналам связи. Стоимость согласуется отдельно.

Перед публикацией нужно актуализировать `/privacy` и `/terms` по данным владельца сайта и фактическим условиям обработки обращений. Тексты главной страницы и сценарии находятся в `content/site.ts` и `components/`.
